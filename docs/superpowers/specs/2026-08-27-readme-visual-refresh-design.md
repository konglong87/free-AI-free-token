# README 视觉刷新设计

## 目标

将根 README 从纯文本清单升级为居中展示型项目首页：首屏突出项目名与定位，提供徽章和快速入口，中段展示真实证据图片，随后保留可扫描的供应商表格与仓库规则。

## 版式

1. 使用居中 HTML 区块承载项目名、副标题、徽章和导航链接。
2. 徽章只表达仓库状态、文档格式、供应商数量和模型数量，不引入未经核验的质量承诺。
3. 证据图片使用仓库现有供应商截图，统一限制宽度并提供中文替代文本。
4. 供应商表格继续作为事实索引，保留目录、模型、Base URL 和状态字段。
5. 其他章节保留原有架构、采集边界、模板和贡献流程，仅优化标题层级与导航。

## 约束

- 不新增构建工具、脚本或外部图片资源。
- 不复制其他项目的专名、徽章文案或图片素材。
- 图片只展示仓库已有证据，不将装饰图伪装成事实证据。
- 保持 GitHub Markdown、移动端换行和屏幕阅读器可用性。

## 验证

- `git diff --check`
- `./scripts/validate-layout.sh`
- 检查所有图片路径存在、替代文本非空、关键目录链接有效。
- 搜索 README 中不应出现的专名和敏感字段。
