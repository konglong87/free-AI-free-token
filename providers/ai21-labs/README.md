## 一句话说明

AI21 Labs 提供 Jamba 系列模型 API；当前公开免费清单只确认 Jamba Large 1.7 与 Jamba Mini 2。

## 适合场景

- 长上下文文本生成
- 摘要与知识问答
- 原型开发
- 模型能力对比

## 快速开始

1. 打开 [AI21 Studio API Key 页面](https://studio.ai21.com/account/api-key) 创建 key。
2. 设置 Base URL `https://api.ai21.com/studio/v1`。
3. 从 [模型列表](models.md) 选择模型。
4. 按官方文档发送最小请求并确认接口格式。
